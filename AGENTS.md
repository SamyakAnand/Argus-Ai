# ARGUS AI repository notes

- This repository is ARGUS AI. Keep its identity and work separate from NEXUS; do not edit the NEXUS checkout.
- The legacy `/workspace` and dataset APIs are structured-data analytics. Do not describe them as knowledge retrieval.
- The `/knowledge` API is a local lexical evidence prototype for Markdown/UTF-8 text. It returns excerpts and source offsets, not generated answers, semantic scores, or security isolation.
- Preserve existing Git history and user changes. Do not commit, push, or deploy without explicit authorization.
- Before editing Next.js files, follow `apps/web/AGENTS.md` and consult the installed Next.js docs for the relevant API.
- Report only checks actually run and capabilities verified in code.
